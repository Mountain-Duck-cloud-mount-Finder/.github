# Mountain Duck — Mount Clouds and Servers (FTP, SFTP) in Finder

## About Mountain Duck

Mountain Duck provides seamless access to remote servers and cloud storage by mounting them as local drives in Finder (macOS) and File Explorer (Windows). Mountain Duck supports FTP, SFTP, WebDAV, Amazon S3, Backblaze B2, Google Drive, Dropbox, OneDrive, SharePoint, OpenStack Swift, Azure Blob, and 20+ other services. Mountain Duck combines bookmark management, file streaming (on-demand download), transparent upload (save locally, auto-sync to server), and Finder integration (drag-drop, Quick Look, Spotlight search). Mountain Duck enables users to work with remote files exactly like local files — from any application. Mountain Duck is trusted by web developers, system administrators, photographers, videographers, and IT professionals who need remote file access without manual transfers.

## Deep Dive — Mount Remote Servers in Finder

Supported protocols — FTP, FTPS, SFTP, WebDAV, WebDAVS (HTTPS), Amazon S3, Backblaze B2, Google Drive, Google Cloud Storage, Dropbox, OneDrive, SharePoint, OpenStack Swift, Azure Blob, Rackspace Cloud Files, Akamai NetStorage, and S3-compatible services (Wasabi, MinIO, DigitalOcean Spaces, Linode, etc.)  
Mounting — each connection appears as external drive in Finder sidebar, drive icons, full read/write access  
File streaming — browse remote folders without downloading, open files on-demand (downloads when opened), optional pinning for offline access  
Transparent transfers — save changes to any application, Mountain Duck uploads in background, resume interrupted transfers  
Finder integration — drag-drop between local and remote, Quick Look (spacebar preview), Spotlight search, tags, color labels, custom icons  
Performance — multi-threaded transfers, bandwidth throttling, concurrent connections, connection keep-alive

## Quick Reference for Mountain Duck

| Operation | Mountain Duck Action |
|-----------|----------------------|
| Add new bookmark | Click + → Choose protocol → Enter server details → Save |
| Mount bookmark | Click bookmark → Mount |
| Unmount drive | Right-click mounted drive → Eject (or drag to Trash) |
| Open mounted drive | Click drive in Finder sidebar |
| Pin folder offline | Right-click folder → Pin |
| Clear cache | Preferences → Cache → Clear |
| View transfers | Click Mountain Duck menu icon → Transfers |
| Set bandwidth limits | Preferences → Bandwidth → Set upload/download max |
| Auto-mount at login | Preferences → General → Mount at startup |
| Open preferences | Cmd+, |
